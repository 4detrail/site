v1.1.7

Modrinth entegrasyonu: binlerce mod tek yerden

Modrinth üzerindeki modlara doğrudan Aperon Launcher içinden ulaşabilirsiniz. Modları arayın, inceleyin ve indirin. Bağımlılık takibi sayesinde gereken diğer modlar da otomatik tespit edilip indirilir.

Modları kendi dilinizde inceleyin

Mod açıklamalarını Türkçe, Rusça ve İngilizce olarak görüntüleyebilirsiniz.

Daha güvenli güncelleme sistemi

Yeni sürüm bulunduğunda Aperon size güncelleme seçeneği sunar. Karar size aittir; "Şimdi Değil" dediğinizde güncellemeyi kaçırmazsınız. Ayarlardaki periyodik kontrol ile sürümünüzü istediğiniz zaman denetleyebilirsiniz.

FPS ve verimlilik iyileştirmeleri

Arka plan sistemleri baştan optimize edildi. AFK durumunda oyun verimliliği modu 30 FPS ile sınırlandırılır. Sonuç: eski launcher'lara kıyasla %60+ daha fazla FPS ve daha az CPU/RAM kullanımı.

Çökme günlüğü (Crash Log)

Ayarlardaki Crash Log sistemiyle oluşan hata kayıtlarını takip edebilir ve sorunun kaynağı hakkında daha fazla bilgi edinebilirsiniz.

Geliştiriciler için Java ayarları

Java yolu ve Java bağlantılarını ayrıntılı yapılandırabilirsiniz. Eski sürümlerdeki Java sorunlarını önlemek için bu sistem baştan ele alındı.

Sık sorulan sorular

Aperon Launcher tamamen ücretsiz mi?

Evet, tüm özellikleri ücretsiz. Reklam ve veri satışı yok.

Launcher güvenli midir?

Evet. VirusTotal'da kontrol edilmiştir.

Otomatik güncelleme nasıl çalışıyor?

Yeni sürüm çıktığında launcher size sorar. Onay verirseniz güncellenir; sessizce güncelleme yapılmaz.

Modrinth modları kolay yükleniyor mu?

Evet. Bağımlı modlar otomatik indirilir. Modrinth hız limitine çarparsa launcher bekler ve yeniden dener.

Hangi Minecraft versiyonlarını destekliyor?

Vanilla, Forge ve Fabric loader'larını destekler. Tüm Minecraft: Java Edition sürümleriyle uyumludur.

Minimum sistem gereksinimleri nelerdir?

Windows 10/11 64-bit, Intel i3 / Ryzen 3, 4 GB RAM. Launcher donanımınızı analiz edip uygun ayarları önerir.
